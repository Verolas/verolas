# packages/

Reusable libraries consumed by apps and services in the Verolas monorepo. Each subdirectory is a pnpm workspace.

Today this directory ships two placeholders:

- `config` shared TS, lint, format, and Tailwind config
- `ui` shared design system primitives for the web app

Additional packages (geometry primitives, citation models, agent SDK, FEA bindings) are added as their workstreams come online.
